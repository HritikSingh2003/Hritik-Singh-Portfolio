# Hritik Singh — Data Analyst Engineer Portfolio

## Files
- `index.html` — portfolio website
- `resume.pdf` — resume linked from the website

## Preview locally
Double-click `index.html` to open it in a browser. Keep `index.html` and `resume.pdf` in the same folder.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new **public** repository (for example, `hritik-singh-portfolio`).
2. Upload `index.html` and `resume.pdf` from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to finish publishing; the public URL will be shown on the Pages settings screen.

This package is ready to upload, but it is not publicly hosted yet.
